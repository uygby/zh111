# 系统使用说明

**系统名称**：工业设备轴承故障智能监测与诊断系统
**版本**：v1.0（阶段四五六）

---

## 1. 环境要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| Python | 3.13+ | 建议 3.10 以上 |
| numpy | 2.x | 数值计算 |
| scipy | 1.x | 信号处理、.mat 解析、FFT |
| scikit-learn | 1.x | 机器学习模型 |
| flask | 3.x | Web 后端 |
| flask-cors | 6.x | 跨域支持 |

安装依赖：

```powershell
pip install -r requirements.txt
```

---

## 2. 快速启动

```powershell
# 1. 进入项目目录
cd zh111

# 2. 启动 Web 服务
python web/app.py

# 3. 浏览器访问
# 打开 http://127.0.0.1:5000
```

启动成功后，控制台会打印数据目录、数据库路径等信息：
```
数据目录: ...\data\cwru
数据库: ...\data\bearing_system.db
访问: http://127.0.0.1:5000
```

> 如需局域网访问（例如答辩现场投影演示），修改 `web/app.py` 末尾：
> ```python
> app.run(host="0.0.0.0", port=5000, debug=False)
> ```
> 然后通过本机局域网 IP 访问，例如 `http://192.168.x.x:5000`。

## 3. 界面操作指南

系统界面分为四大功能区域：

### 3.1 数据选择（左侧）
1. 在**数据集下拉框**中选择数据文件（文件名包含故障类型、直径、负载信息）；
2. 点击 **【加载数据】**，中间区域将显示该数据的**振动波形图**和**频谱图**；
3. 下方显示数据元信息：故障类型、数据长度、转速、负载。

### 3.2 故障诊断（右侧）
1. 加载数据后点击 **【故障诊断】**；
2. **诊断结果**区显示：故障名称、故障代码、严重程度、置信度；
3. **运维建议**区通过知识推理自动生成：检修优先级、故障成因、处理建议、检查清单；
4. 重度/中度故障自动写入**告警记录**，并触发告警横幅提示。

### 3.3 健康趋势预测（中间下方）
1. 点击 **【健康趋势预测】**；
2. 生成**健康退化趋势图**（蓝色=历史健康指标，红色虚线=趋势预测，橙色点线=预警阈值）；
3. 左侧**健康度**实时更新（当前值 → 预测末端值），超出阈值时触发预警。

### 3.4 记录管理（底部）
- **诊断记录**：历史诊断的时间、类型、置信度；
- **告警记录**：触发告警的时间、类型、描述。

## 4. REST API 说明

| 接口 | 方法 | 参数 | 返回 |
|---|---|---|---|
| `/api/health` | GET | — | 服务状态、模型加载状态 |
| `/api/datasets` | GET | — | 数据集列表（文件名/类别/直径/负载） |
| `/api/signal/<filename>` | GET | 文件名 | 波形、频谱、元信息（抽稀后） |
| `/api/diagnose` | POST | `{"filename": "..."}` | 诊断结果（类型/置信度/严重度/建议） |
| `/api/predict` | POST | `{"filename": "...", "metric": "rms"}` | 健康趋势序列、阈值、健康度、预警 |
| `/api/reason` | POST | `{"fault_type": "IR"}` | 知识推理（成因/建议/检查清单） |
| `/api/knowledge` | GET | — | 知识库全部条目 |
| `/api/records` | GET | — | 诊断记录与告警记录 |

## 6. 常见问题

| 问题 | 解决 |
|---|---|
| 端口被占用 | 修改 `web/app.py` 中 `app.run` 的 port 参数 |
| 模型未加载（界面显示"模型未加载"） | 运行 `python scripts/train_classifier.py` 重新训练 |
| 页面图表不显示 | 确认访问的是 `http://127.0.0.1:5000`（非文件路径），ECharts 已本地化无需联网 |
| 中文乱码 | 确保系统字体含微软雅黑/黑体（Windows 默认满足） |
