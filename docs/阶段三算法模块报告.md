# 阶段三：算法模块开发与模型训练报告

> 智造24-2-25 张昊 · 工业设备轴承故障智能监测与诊断系统
> 对应方案设计阶段三（9/1–9/5）：故障分类、时序预测、知识推理算法模块开发与模型训练

## 一、实验数据

本阶段使用 CWRU 12k 驱动端数据 20 个 .mat 文件（0~3 HP 负载混合），
经「滑动窗口切片（1024 点/512 步长）→ z-score 标准化 → 特征提取（20 维）」处理后，
得到特征数据集：

| 类别 | 样本数 |
| --- | --- |
| 正常（Normal） | 2366 |
| 内圈故障（IR） | 2363 |
| 滚动体故障（B） | 711 |
| 外圈故障（OR） | 949 |
| **合计** | **6389** |

特征组成：12 个时域特征（均值、RMS、峭度、峰值因子等）+ 8 个频域特征（频谱质心、主频幅值等）。

## 二、故障分类模块

### 2.1 模型与流程

使用 `scikit-learn` 构建三类候选模型，均包装为「StandardScaler 特征标准化 + 分类器」Pipeline：

- **KNN**（k=5）
- **SVM**（RBF 核，C=10）
- **随机森林**（200 棵树）

### 2.2 评估结果

| 模型 | 随机划分准确率 | 5 折交叉验证 | 按文件分组准确率 |
| --- | --- | --- | --- |
| KNN | 0.978 | 0.835 ± 0.090 | — |
| SVM | 0.992 | 0.844 ± 0.125 | — |
| **随机森林** | **0.997** | **0.891 ± 0.070** | **0.633** |

随机森林表现最优，作为最终模型保存（`models/fault_classifier.pkl`）。

### 2.3 数据泄漏问题与严谨评估（重要发现）

- **随机划分**（按样本分层切分）时准确率高达 **0.997**；
- 但**按文件分组**（GroupShuffleSplit，同一 .mat 文件的窗口不跨训练/测试集）后，
  准确率降至 **0.633**。

**原因分析**：滑动窗口步长（512）小于窗口长度（1024），相邻窗口存在 50% 重叠，
数据高度相关；随机划分时，同一文件的相似窗口同时进入训练与测试集，导致
**信息泄漏**，虚高了准确率。

**结论**：
1. 课程实验中必须采用按文件/按设备分组的评估方式，才能反映模型真实泛化能力；
2. 当前 0.633 的跨文件准确率说明模型已学到一定的故障类别可分性，但受限于
   样本规模（20 个文件）与工况多样性，泛化仍有提升空间；
3. 提升方向：扩大数据集（更多负载/设备工况）、增加特征、数据增强。

## 三、健康趋势预测模块

### 3.1 实现方案

- 沿振动信号滑动窗口构建健康指标序列（RMS / 峭度）；
- 基于最小二乘多项式回归拟合退化趋势并外推预测未来指标；
- 将健康指标映射为 0~100 健康度，设定预警阈值（历史 90 分位）自动判警。

### 3.2 演示结果（内圈故障信号）

| 指标 | 数值 |
| --- | --- |
| 历史窗口数 | 237 |
| 基准值 / 预警阈值 | 0.450 / 0.565 |
| 当前值 / 预测末端值 | 0.495 / 0.529 |
| 当前健康度 / 预测末端健康度 | 60.9 / 31.4 |
| 趋势斜率 | +3.5e-5（缓慢退化） |

说明：CWRU 为稳态故障数据（非真实退化数据），本模块以振动能量（RMS）随时间的
演变近似健康退化过程，用于演示「趋势预测 + 早期预警」完整逻辑；实际工程中应
替换为真实设备退化监测数据（如传感器长期连续采集）。

## 四、故障知识推理模块

### 4.1 实现方案

构建「故障类型 - 成因 - 特征表现 - 处理建议 - 检查清单」知识库，覆盖 4 类状态；
基于规则推理（If-Then）：
- **严重程度判定规则**：峭度 ≥ 8 → 重度；峭度 ≥ 5 → 中度；峭度接近正常但
  RMS 偏高 → 中度；否则轻度；
- **处置优先级**：重度 → 紧急停机更换；中度 → 近期检修；轻度 → 例行监测。

### 4.2 推理示例

| 诊断结果 | 严重程度 | 核心建议 |
| --- | --- | --- |
| 正常 | 轻度 | 保持润滑周期，定期监测趋势 |
| 内圈故障 | 中度 | 停机检修，检查内圈滚道，核查装配过盈与润滑 |
| 滚动体故障 | 轻度 | 检查滚动体表面，尽早更换（发展快） |
| 外圈故障 | 中度 | 检修外圈滚道与轴承座配合，中度以上更换轴承 |
