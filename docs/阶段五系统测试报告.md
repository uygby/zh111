| `/api/records` | GET | 诊断/告警记录查询 |

## 5. 测试中发现的问题与修复

| # | 问题 | 原因 | 修复方案 | 状态 |
|---|---|---|---|---|
| 1 | ECharts CDN 加载失败导致前端整体无法初始化 | staticfile CDN 资源不可达（net::ERR_ABORTED），`echarts is not defined` | 将 ECharts 5.5.1 下载本地化至 `web/static/js/echarts.min.js`（npmmirror 国内源） | ✅ 已修复 |
| 2 | 正常数据文件 rpm 显示为 `null` | normal_0_97.mat 内不含转速变量，后端 rpm 为 None | 后端 API 层增加 CWRU 负载-转速标准映射兜底（0→1797, 1→1772, 2→1750, 3→1730 rpm） | ✅ 已修复 |
| 3 | Flask debug 热重载在编辑中间态崩溃 | 编辑 app.py 过程中产生瞬时语法错误，debug 重载进程退出 | 修复语法后重启服务 | ✅ 已解决 |

## 6. 系统运行方式

```powershell
cd zh111
python web/app.py
# 浏览器访问 http://127.0.0.1:5000
```

- 默认监听 `127.0.0.1:5000`（仅本机访问）；
- 如需局域网演示，将 `web/app.py` 中 `app.run` 的 host 改为 `0.0.0.0`；
- 数据库与诊断记录自动持久化于 `data/bearing_system.db`。
